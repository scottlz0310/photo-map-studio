## 実機検証

| 対象 | 確認結果 |
| --- | --- |
| #60 国外 × 地理院ベクトル | パリの合成写真で OSM 地図へプレビューが切り替わる。一括生成は成功 4・スキップ 2・エラー 0。履歴の内訳はパリが `TileNotFound` / HTTP 404、GPS なしが `MissingGps`。国外の白紙画像は生成されない |
| #61 使用量表示 | 地理院ベクトルのプレビュー後 1.6 MB、一括生成後 2.7 MB と更新された |
| #64 盾と道路名 | 東京の道路写真を OpenFreeMap で生成（800×600、ズーム 15）。国道 1 の青い盾、高速 C1 等の緑の盾、道路名が出力画像に描画された |
| #63・#70 F1 ヘルプ | F1 で開閉でき、生成オプションにピン形状、アンカー、1024 MB の既定上限、LRU 整理と使用量表示の説明がある |
| #63 OpenFreeMap の 101 枚確認 | タイトルが「OpenFreeMap で101枚を一括生成」。3,000 タイル／50 MB、並列 4 以内、アプリは 1 接続ずつ取得する旨を表示。「カスタム配信元」「1 秒間隔」の誤記はない。キャンセル後は処理済み 0・全 101 枚、生成処理のタイル取得 0 件 |

実機スクリーンショットと出力画像は所有者の監査資料 `v0.3.0-chk/` に保管する。写真や端末固有のパスをリポジトリに追加しない。

## 未実施と残課題

- ARM64 実機、署名済み MSIX の新規インストール、App Installer 更新、オフライン動作（#57）、コマンドライン起動、OSM ラスター・カスタム URL・ループバックの回帰、数千枚規模のバッチは今回未実施。
- 道路名の折れ線追従は #56、オフライン耐性は #57 に残る。OpenFreeMap のキャッシュは配信バージョンごとに分離する。
- カスタム HTTP 配信元が 404 を返した場合のプレビューは OSM へ切り替わる。プリセットだけに切り替えを限定する仕様変更は所有者の判断待ち。ローカル PMTiles は切り替え対象外。
- #71 のマージ、Prepare Release の起動と正式公開は所有者の明示許可後に行う。新しい段階公開フローの端から端までの動作確認は公開作業時に実施する。
