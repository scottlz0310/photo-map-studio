# ベクター地図の PoC 品質回復と道路名注記（#56）

## 目的と判定基準

v0.3.0 の出力と採用前の OpenFreeMap 版 PoC に、道路の配色・太さ、建物輪郭、土地利用、河川名、施設マーカー、道路名配置の差があった。所有者は PoC 品質の回復と細街路名を優先し、#56 の折れ線追従も同じ PR で実装する方針を承認した。

- 道路・建物・土地利用の識別性を PoC の表現に戻す。
- 配信データにある生活道路名を z15 以降、小道・歩道等を z17 以降で表示対象にする。
- 道路名を地名・施設より優先し、線形状へ追従させる。急カーブや短い区間では無理に描かず、同じ道路の別の可視区間も試す。
- 近接する同名注記をタイルをまたいで抑止する。同名の別道路や遠方の町名まで一律に消さない。

## 実装上の判断

- 文字を歪めず、SkiaSharp のパス上のグリフ回転で描く。配置区間を独立したパスに切り出し、衝突判定と実描画の位置を一致させる。
- 線注記の衝突判定は短い区間ごとの矩形を一括登録する。途中で衝突した場合は一切登録しない。曲線全体の大きな矩形で周辺の細街路名まで消すことを避ける。
- 全タイルの盾 → 全タイルの道路名 → 地名・河川名・施設の順で配置する。
- 地理院は [公式データ項目一覧](https://maps.gsi.go.jp/help/pdf/vector/optbv_dataspec.pdf) の `Anno` が point/line を持つことに基づき、線注記だけを追従させる。点注記を近傍道路へ推測で結び付けない。
- 外部ライブラリ・配信元・最大取得ズーム・キャッシュ鍵は変更しない。

## 保存タイルによる目視比較

2026-10-23、Windows / x64、.NET SDK 10.0.402、SkiaSharp 4.153.1 で実施。

- 変更前は v0.3.0 の公開 SHA `9d87dfca7880eb2e5d78b506fcba7a6ca90abab3`。
- PoC の保存 PBF を双方に渡し、同じ座標・800×600・z16〜19 で比較した。新しい通信・元写真の変更・インストール済みアプリの設定変更は行っていない。
- 一市町村の中心部で、主要道路の橙／黄色、生活道路の白、建物輪郭、河川名、施設の丸、小道の破線、道路名の道路沿い配置を確認。z18/19 でも画面内の可視区間に名称と盾が残る。
- 都市部・国外の z18 でも、施設と道路名が道路・建物に対応して配置されることを確認した。
- 比較画像は所有者の監査資料 `v0.3.0-chk/vector-quality/` に保管する。端末固有のパス・元写真・地名を本文やテストへ追加しない。

再現用スクリプトは `scripts/Export-VectorMapComparison.ps1`。`<cache>` には `{z}_{x}_{y}.pbf` 形式の保存 OpenFreeMap タイルを渡す。必要なタイルがなければ失敗し、ネットワークで補完しない。

```powershell
./scripts/Export-VectorMapComparison.ps1 -TileCachePath <cache> -OutputDirectory <after> -Latitude <lat> -Longitude <lon>
# 同じスクリプトから変更前の checkout を指定して比較する。
./scripts/Export-VectorMapComparison.ps1 -TileCachePath <cache> -OutputDirectory <before> -Latitude <lat> -Longitude <lon> -RepositoryPath <v0.3.0-checkout>
```
