PhotoMapStudio プライバシーポリシー

制定日: 2026年8月15日 / 更新日: 2026年10月23日

収集する情報

PhotoMapStudio は、ユーザーが選択した写真ファイルを端末上で読み取り、EXIF GPS 情報を地図画像の生成に使用します。写真本体、EXIF 情報、生成画像を開発者のサーバーへアップロードする機能はありません。

外部通信

地図画像を生成するため、選択されたタイルソースへ地図タイルを要求します。通信先は次のとおりです。

  • 国土地理院の地理院タイル（淡色・標準。既定）: cyberjapandata.gsi.go.jp へタイル画像を要求します。
  • 国土地理院の最適化ベクトルタイル: 同ホストの PMTiles アーカイブへ、必要な範囲だけを HTTP Range 要求で取得します。
  • OpenFreeMap（ベクター）: tiles.openfreemap.org へ、最新の配信版を調べる TileJSON と、ベクタータイル（PBF）を要求します。
  • OpenStreetMap: 対話プレビューで選択したとき、または地理院タイルが配信されていない場所（国外など）でプレビューを表示するときに、タイル画像を要求します。一括生成では使用しません。
  • ユーザーが設定した配信元: 「カスタム」で指定したタイル URL、「カスタム（ベクター）」で指定した PMTiles の URL またはベクタータイルの URL へ要求します。通信先はユーザーが指定したものであり、本アプリは配信元を判断・制限しません。

「カスタム（ベクター）」で、この PC 上の PMTiles ファイルを指定した場合は、ファイルを端末上で読み取るだけで、通信せず、ファイルの複製も保存しません。範囲外の写真でも、外部のタイル配信元へ切り替えません。

タイルの要求 URL には、地図上の位置から算出したタイル座標が含まれるため、タイル提供元には要求地点が伝わる場合があります。PMTiles では、要求するデータの範囲（HTTP Range）から同様に伝わる場合があります。要求には通常、アプリケーションの User-Agent、ネットワークに必要な標準情報も含まれます。写真本体、EXIF 情報、GPS の座標そのものを外部へ送信することはありません。タイル提供元の利用規約・プライバシーポリシーも確認してください。ユーザー指定の URL に認証情報（ユーザー名・パスワード）を含めることはできません。

ローカル保存

取得した地図タイル（ラスター画像とベクタータイル）は、再利用と通信量削減のため端末上のキャッシュへ保存されます。OpenFreeMap の最新の配信版を示す URL も、オフライン時に前回の版を使うためキャッシュへ保存します。キャッシュは既定で 30 日間保持し、合計が容量上限（既定 1 GB。設定画面で変更できます）を超えると、最近使われていないものから自動的に削除します。設定画面の「キャッシュ消去」でいつでもすべて削除できます。この PC 上の PMTiles ファイルを指定した場合、その内容はキャッシュしません。

設定、ウィンドウ状態、キャッシュはユーザーの端末内で管理され、アプリから外部へ同期されません。設定には、入力・出力フォルダのパス、タイルソースの選択、ユーザーが指定したタイル URL・PMTiles の URL またはファイルパス・出典表示などが含まれます。

読み取り・生成・保存のエラー時には、端末内のアプリ保存先 LocalState/diagnostics に診断ログを保存します。記録するのは時刻、処理段階、対象番号、アプリのバージョン、例外の種類、HResult、呼び出しメソッド名です。写真、GPS、ファイルパス、URL、例外メッセージは記録せず、ログを外部送信する機能はありません。現行と直前のファイルを各1MiB、合計最大2MiBまで保持し、上限に達すると古い記録を置き換えます。保存先の詳しい場所はアプリ内ヘルプの「トラブルシューティング」で確認できます。

一括生成の結果確認用に、別の保存先 LocalState/batch-history へ実行履歴を自動保存します。実行日時、入力フォルダのパス、スキップ・エラーのファイル相対パスと結果・理由、HTTP状態、例外型・HResult、成功・スキップ・エラー等の集計を記録します。フォルダ読み取り失敗や、キャンセル・途中中止までの結果も保存します。成功した写真は集計のみを残します。直近30回を保持し、正常保存後に古い履歴を自動整理します。写真本体、GPS、タイルURL、例外メッセージは含まず、履歴を外部送信する機能はありません。保存や整理に失敗した場合は画面へ通知します。

解析・広告

本アプリは、広告配信、行動解析、アカウント登録を行いません。

配布・問い合わせ

アプリは GitHub Releases と Windows App Installer を通じて配布します。配布ページへのアクセス時には GitHub のポリシーが適用されます。問い合わせは GitHub Issues で受け付けます。ポリシーを変更する場合は、このページの制定日を更新します。
