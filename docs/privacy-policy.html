PhotoMapStudio プライバシーポリシー

制定日: 2026年8月15日

収集する情報

PhotoMapStudio は、ユーザーが選択した写真ファイルを端末上で読み取り、EXIF GPS 情報を地図画像の生成に使用します。写真本体、EXIF 情報、生成画像を開発者のサーバーへアップロードする機能はありません。

外部通信

地図画像を生成するため、選択されたタイルソースへタイル画像を要求します。既定の地理院タイル、OpenStreetMap、ユーザーが設定した任意のタイル URL が対象です。タイル URL には地図上の位置から算出したタイル座標が含まれるため、タイル提供元には要求地点が伝わる場合があります。要求には通常、アプリケーションの User-Agent、ネットワークに必要な標準情報も含まれます。タイル提供元の利用規約・プライバシーポリシーも確認してください。

  • 地理院タイルの利用について
  • OpenStreetMap Tile Usage Policy

ローカル保存

取得した地図タイルは、再利用と通信量削減のため端末上のキャッシュへ保存されます。設定、ウィンドウ状態、キャッシュはユーザーの端末内で管理され、アプリから外部へ同期されません。

解析・広告

本アプリは、広告配信、行動解析、アカウント登録を行いません。

配布・問い合わせ

アプリは GitHub Releases と Windows App Installer を通じて配布します。配布ページへのアクセス時には GitHub のポリシーが適用されます。問い合わせは GitHub Issues で受け付けます。ポリシーを変更する場合は、このページの制定日を更新します。
