# PhotoMapStudio ユーザーガイド

PhotoMapStudio は、写真の EXIF GPS 情報から、撮影地点を中心とした地図画像を生成・一括出力する Windows アプリケーションです。この文書は、実際に使うときの手順と注意点をまとめたマニュアルです。アプリ内のヘルプ（`F1`）と同じ内容を扱います。

- 対応する入力形式: JPEG / TIFF / HEIC
- 出力形式: PNG
- 設計や検証の記録は [開発者向けの文書](development/README.md) にあります。

## システム要件

- Windows 10 バージョン 22H2（ビルド 19045）以降、または Windows 11
- x64 または ARM64 プロセッサ
- インターネット接続（地図タイルの取得に使います。取得済みのタイルはキャッシュから使えます）

## インストールと更新

[GitHub Releases](https://github.com/scottlz0310/photo-map-studio/releases) の最新版から入手します。署名済みの MSIX を、App Installer 経由で導入します。

### インストールスクリプトを使う方法（推奨）

最新版に添付されている `Install-PhotoMapStudio.ps1` を、PowerShell で実行します。署名証明書の登録（初回のみ、管理者の確認が表示されます）と、アプリの導入を行います。

```powershell
powershell.exe -ExecutionPolicy Bypass -File .\Install-PhotoMapStudio.ps1 -Architecture x64
```

ARM64 の PC では `-Architecture arm64` を指定します（省略すると、PC に合わせて自動で選びます）。

### 手動で導入する方法

最新版に添付されている公開証明書（`PhotoMapStudio.cer`）を、「ローカル コンピューター」の「信頼された人」ストアへ登録してから、お使いの PC に合う `.appinstaller`（`PhotoMapStudio-x64.appinstaller` または `PhotoMapStudio-arm64.appinstaller`）を開きます。

### 更新

導入後は、Windows が約 8 時間間隔でバックグラウンドで更新を確認し、新しい版があれば適用します。更新の反映は PC の稼働・通信状況により遅れることがあります。すぐに更新する場合は、最新版の該当アーキテクチャの `.appinstaller` を開きます。

### アンインストール

Windows の「設定」の「アプリ」から削除します。

## クイックスタート

1. **入力フォルダ**を指定します。必要なら「下位フォルダも探索する」を有効にします。
2. **出力フォルダ**を指定します。`.` を指定すると、写真と同じフォルダに保存します。
3. **プレビュー**で、位置・サイズ・ズームを確認します。
4. **一括生成**を押し、進捗と結果を確認します。

初回はタイルの取得が必要です。まず 100 枚程度で確認し、1,000 枚、5,000 枚へ段階的に増やしてください。

## フォルダと出力ファイル名

### 入力フォルダ

- 既定では、指定したフォルダの直下だけを探索します。「下位フォルダも探索する」を有効にすると、入力からの相対パス順に処理します。
- 再帰探索では、リンク／ジャンクションとシステムフォルダを除外します。Dropbox などのクラウド同期ファイルは対象です。
- 読み取れないフォルダは ERROR として記録し、処理を続けます。

### 出力フォルダ

- **絶対パス**（UNC を含む）は、すべての写真に共通の出力先です。
- **相対パス**は、各写真のフォルダを基準に解決します。`.` は写真と同じ場所、`maps` は写真のフォルダ内の `maps`、`out\map` はその下の `map` に保存します。
- `..` で外へ出る指定、ルート相対、ドライブ相対は指定できません。
- GPS がなくてスキップする写真のフォルダには、相対出力フォルダを作りません。

```text
入力
写真/
├─ 春/IMG_0001.jpg
└─ 秋/IMG_0001.jpg

出力先: maps、先頭文字: map_、末尾文字: _z16
写真/
├─ 春/
│  ├─ IMG_0001.jpg
│  └─ maps/map_IMG_0001_z16.png
└─ 秋/
   ├─ IMG_0001.jpg
   └─ maps/map_IMG_0001_z16.png
```

### 出力ファイル名

出力名は「先頭文字 + 元写真の拡張子なしの名前 + 末尾文字 + `.png`」です。既定は、先頭文字なし・末尾文字 `_map` です（例: `IMG_0001.jpg` → `IMG_0001_map.png`）。設定欄に、入力した名前の例が表示されます。

- `\ / : * ? " < > |` と制御文字は使えません。
- 写真と同じ場所に保存する場合は、写真を上書きしないよう、先頭文字か末尾文字を指定してください。
- 出力名が 255 文字を超える写真は ERROR になります。
- 出力の衝突は最終パスで判定し、生成前に全体を中止します。絶対パスの出力と再帰探索を組み合わせると、別のフォルダの同名の写真も衝突します。

## 生成オプション

| 項目 | 内容 |
| --- | --- |
| 幅・高さ（px） | 出力画像のサイズ。既定は 800×600 |
| ズームレベル | 大きいほど狭い範囲を詳しく表示。既定は 15。範囲はタイルソースごとに異なります |
| タイルソース | 地図の種類。[後述](#タイルソースと利用条件) |
| ピン形状 | 撮影地点に合成する印 |
| キャッシュ容量上限（MB） | 既定は 1024 MB。[後述](#キャッシュ) |

### ピン

緑ピン・赤ピン・青ピン（同梱）、二重円ターゲット、十字ターゲット（測量風）、カスタム画像から選びます。

- カスタム画像は PNG のパスを指定します。未指定では既定のピンを使います。
- **アンカー基準点**（カスタム画像のとき）: 「下端中央」はピンの先端が、「中央」は図心やターゲットの中心が撮影地点になります。同梱のピンとターゲットは、形に合わせて固定です。

## プレビュー

写真を列挙したあと、GPS 付きの写真を見つけた順に一覧へ追加し、最初の 1 枚で地図を表示します。

- 一覧は相対パスで、同名の写真を区別します。
- 対象の写真・ズーム・サイズを変えると、自動で再生成します。
- 読み込みをキャンセルしても、見つかった候補と生成済みの画像は残ります。
- 地理院タイルが配信されていない場所（国外など。HTTP 404）では、対話プレビューに限り OpenStreetMap へ切り替えます。**この切り替えでは、撮影地点のタイル座標が OpenStreetMap へ送られます。** 一括生成では切り替えません。
- 「カスタム（ベクター）」でこの PC 上の PMTiles ファイルを指定した場合は、収録範囲外でも外部へ切り替えず、地図を作れないエラーとして表示します。

## タイルソースと利用条件

生成した画像には、配信元の出典表示を焼き込みます。利用条件は配信元ごとに異なるため、一括生成の前に確認してください。

### プリセット

| タイルソース | 提供元 | ズーム | 備考 |
| --- | --- | --- | --- |
| **地理院タイル（淡色）** | 国土地理院 | 5–18 | **既定**。日本国内のみ |
| 地理院タイル（標準） | 国土地理院 | 5–18 | 日本国内のみ |
| 地理院タイル（最適化ベクトル） | 国土地理院 | 4–18 | 等高線・道路縁・公的注記。PMTiles を範囲取得して直接描画 |
| OpenFreeMap（ベクター） | OpenFreeMap / OpenStreetMap | 0–19 | 全世界対応。文字切れのない鮮明な表示。国道・都道府県道などの経路番号の盾と道路名を描画 |
| OpenStreetMap | OpenStreetMap contributors | 0–19 | **対話プレビュー用**（ラスター）。一括生成は使えません |

- OpenStreetMap の公式サーバーは、一括取得（bulk downloading）を禁じています。直列取得や減速でも、この禁止は解除されません。一括生成には、一括取得・画像保存を許可する OpenStreetMap 系の配信元を「カスタム」で指定してください。
- 国土地理院タイルの利用は、[国土地理院コンテンツ利用規約](https://www.gsi.go.jp/kikakuchousei/kikakuchousei40182.html)と、各タイルの利用手続に従ってください。
- OpenFreeMap の[利用規約](https://openfreemap.org/tos/)は、まとまった取得を 1 回あたり 3,000 タイルまたは 50 MB 以内・並列 4 以内とし、それを超える場合は運営への連絡を求めています。

### カスタム（URL）

`http(s)` の URL テンプレートと出典を指定します。

```text
https://example.com/{z}/{x}/{y}.png
```

- 認証情報（ユーザー名・パスワード）を URL に埋め込まないでください。設定とエラー表示には URL が含まれます。
- 一括生成は、1 接続・1 秒間隔で取得します。

### カスタム（ベクター）

利用者が用意したベクタータイルを、直接描画します。

| 場所の指定 | 内容 |
| --- | --- |
| PMTiles ファイル | この PC 上の `.pmtiles`（絶対パス）。通信しません |
| PMTiles の URL | `https://…/….pmtiles`。必要な範囲だけを HTTP Range 要求で取得します |
| ベクタータイルの URL テンプレート | `https://…/{z}/{x}/{y}.pbf`（MVT / PBF）。**配信する最大ズーム**（0〜19、既定 14）も指定します |

- **レイヤー構成（スキーマ）**は、配信元のデータに合わせて「OpenMapTiles」か「国土地理院 最適化ベクトル」を選びます。データと異なるスキーマを選ぶと、エラーにはならず背景だけの地図になります。
- **出典表示は必須**です。生成画像に焼き込みます。
- 配信元の利用条件と帰属表示は、利用者が確認してください。
- 取得は、1 接続ずつ 125 ミリ秒以上の間隔で行います（PMTiles は範囲取得）。

### 配信元ごとの一括生成の取得方式

| 配信元 | 取得方式 | 100 枚超の確認 |
| --- | --- | --- |
| 地理院タイル（淡色・標準） | 最大 4 並列・50 ミリ秒以上の間隔 | なし |
| 地理院タイル（最適化ベクトル） | PMTiles を最大 2 並列で範囲取得 | なし |
| OpenFreeMap | 1 接続ずつ順に取得 | あり |
| カスタム（URL） | 1 接続・1 秒間隔 | あり |
| カスタム（ベクター）の HTTP | 1 接続ずつ 125 ミリ秒以上の間隔 | あり |
| この PC 上の配信元（`localhost`、`127.0.0.0/8`、`::1`） | 8 並列・5 ミリ秒間隔 | なし |
| この PC 上の PMTiles ファイル | 通信しません | なし |

- 100 枚を超える一括生成で確認が必要な配信元では、開始前に確認画面が表示されます。配信元が一括取得・画像保存を許可していることを確認してから開始してください。
- LAN やプライベート IP は、この PC 上の配信元には含みません。ループバックの先が他者のサーバーへの転送（SSH のポートフォワードなど）の場合も同じ間隔になるため、その場合は使わないでください。
- 404 以外の取得失敗が連続 10 件になると、中止します。自動再試行はしません。`Retry-After` は、再実行の時期を判断できるよう表示します。
- 進捗には、タイルのネットワーク取得／キャッシュ命中の件数と、平均レート／直近 1 秒の最大要求数を表示します。この PC 上のファイルの読み取りは数えません。
- 既定の 800×600 では、1 写真あたり 12〜20 タイル程度です。撮影地点が狭い範囲に集まっていれば、タイルを再利用できます。

### 地理院 最適化ベクトルタイルの適用範囲

写真台帳や調査報告書における「参考位置図・背景案内図」としての利用を想定したものです。国土地理院の最適化ベクトルタイルは、測量法に基づく「基本測量成果」そのものとは位置付けられていません。法的証明や基本測量成果自体の添付が厳密に義務付けられている用途（不動産登記・境界確定など）の証明能力は保証しません。厳密な測量成果が必須の提出先には、別途、正規の測量成果交付データなどを確認・利用してください。

## キャッシュ

取得したタイルは、端末内（アプリの保存先 `LocalState/tile-cache`）にキャッシュします。

- **保持期間**: 既定で 30 日。期限切れや消去のあとは再取得します。
- **容量上限**: 既定 1 GB（設定画面の「キャッシュ容量上限（MB）」で変更できます）。合計が上限を超えると、最近使われていないものから自動で削除します。
- **消去**: 設定画面の「キャッシュ消去」で、すべて削除できます。使用量は設定欄に表示します。
- **保存の単位**: 配信元ごとに分かれます（ラスターは URL テンプレートとズーム・座標、ベクタータイルは配信元の識別子とズーム・座標ごと）。配信元が違うタイルは混ざりません。
- OpenFreeMap は、配信の版が更新されると、以前の版のキャッシュは使えず再取得します。オフラインなどで版を調べられない場合は、前回の版のキャッシュを使います。
- キャッシュに命中したタイルは、通信せず、減速もしません。
- この PC 上の PMTiles ファイルは、キャッシュしません。

## 一括生成と結果・履歴

一括生成の進捗は、段階ごとに次のとおり表示します。

- **列挙**: 走査済みのフォルダ数と、検出した写真数（総数は未確定）
- **プレビューの一覧**: 確認済み／全写真数と、GPS ありの件数
- **一括生成**: 処理済み／全写真数、現在の相対パス、成功・スキップ・エラーの件数、経過時間

| 状態 | 意味 |
| --- | --- |
| SUCCESS | PNG を保存しました |
| SKIP | GPS なし、または配信範囲外です |
| ERROR | 読み取り・取得・保存に失敗しました |
| CANCELLED | 利用者が中断しました。作成済みの画像は残ります |

- キャンセルしても、完成済みの画像は削除しません。書き込み途中の `.tmp` は片付けます。
- 再実行は最初から上書き生成します。生成済みの画像をスキップする再開には対応していません。

### 実行履歴

進捗ログの「スキップ・エラーの実行履歴」から実行を選ぶと、元の入力フォルダ、写真の集計、問題の相対パスと理由を確認できます。ファイル名と理由は、画面から選択してコピーできます。

- 完了、キャンセル、連続失敗による中止、開始・継続エラーまでの確定結果を、端末内（`LocalState/batch-history`）に自動保存します。直近 30 回を保持し、古いものは自動で整理します。
- アプリを再起動しても、履歴を確認できます。
- 記録するのは、実行日時、入力フォルダ、問題の相対パス・結果・理由、HTTP 状態・例外の型・HResult、写真の集計です。成功した写真は集計だけを残し、写真本体・GPS・タイル URL・生の例外メッセージは保存しません。

## コマンドライン

他のツールとの連携用に、起動時の入力・出力フォルダを指定できます。すでに起動している場合は、同じインスタンスへ引数を転送します。

```text
PhotoMapStudio.exe --input-dir "C:\写真 (2026)" --output-dir maps
```

- パスに空白がある場合は、引用符で囲みます。
- `--output-dir` の相対指定も、各写真のフォルダが基準です。
- 再帰探索と付加文字は、画面で設定してください。

## トラブルシューティング

| 症状 | 対処 |
| --- | --- |
| GPS なしでスキップされる | 写真に位置情報があるか確認してください |
| タイルの取得に失敗する | 配信元・HTTP 状態・`Retry-After` を確認し、時間をおいて再実行してください |
| 出力が衝突する | 相対出力に変更するか、写真の名前を変更してください |
| 出力先を作成できない | 保存先の権限とネットワーク接続を確認してください。相対出力の失敗は写真単位で ERROR にして続行し、絶対出力の作成失敗は開始前に中止します |
| 長いパスで失敗する | パッケージと Windows の長いパス対応を確認してください。読み書きに失敗した写真は ERROR になります |
| カスタム（ベクター）で白紙の地図になる | データに合う「レイヤー構成（スキーマ）」を選んでいるか確認してください |
| カスタム（ベクター）で「ベクタータイルとして読み取れません」と表示される | 場所の指定が、PMTiles またはベクタータイル（MVT / PBF）を返しているか確認してください |

### 診断ログ

読み取り・生成・保存のエラーは、端末内のローカル診断ログ（`LocalState/diagnostics`）に記録します。時刻・処理段階・番号・アプリ版・例外の型・HResult・呼び出しメソッドを保存し、写真・GPS・パス・URL・例外メッセージは含めず、外部へ送信しません。現行と直前のログを、各 1 MiB まで保持します。番号 0 は、写真の番号を持たない処理です。

保存先の実際の場所は、アプリ内ヘルプの「トラブルシューティング」に表示されます。

## プライバシーと非保証事項

- 写真本体、EXIF 情報、GPS の座標そのものを、開発者や外部へ送信することはありません。地図タイルを要求するとき、タイルの座標から要求地点が配信元に伝わる場合があります。詳しくは [プライバシーポリシー](privacy-policy.html) を参照してください。
- 利用している地図タイルの著作権と利用条件は、各配信元の規約に従ってください。出典表示は生成画像に焼き込まれます。
- 地理院 最適化ベクトルタイルを含め、生成した地図は、測量成果や法的な証明を保証するものではありません。
- 配信元のサービス内容・利用条件・取得できる範囲は、予告なく変わることがあります。
